## 自检十问

1. **有人在疼吗（不是我觉得）？** 是 —— 两个引擎有多个 open PR / bug 在修，vLLM 还有未落地 RFC（P1/P2/P3）。
2. **有数字吗？** **否** —— 这是当前最大缺口（P1/P2/P3 均为 L0）⇒ **必须先取证**。
3. **现在没人治吗？** 部分有人治：引擎在做**工程修复**（vLLM PR #50172、SGLang PR #28185）；但没看到把它当**资源分配 / 调度**问题的系统研究 ⇒ 待 S3 读正文确认。
4. **能在这台机器上验证吗？** 能 —— ≤8B hybrid checkpoint 可在 96 GB 单卡 bf16 跑；多卡可租。
5. **3–4 周能拿到可信数字吗？** 能到决策级（T0/T1）；论文级需要更多时间。
6. **相对最佳固定配置有 ≥8% 的空间吗？** **未知，必须算**（形态⑤），不能靠直觉。
7. **我把「没人做过」当理由了吗？** 没有（这条恰好相反：有人正在做）。
8. **我的度量口径经得起恒等式检验吗？** 尚未建立 ⇒ 进 S4 前必须建立（`#6` 的教训：口径错会让结论反向）。
9. **结论会不会只在极端角落成立？** 风险实在（P4 就只在长上下文）⇒ 必须在 S5 的网格里显式覆盖极值。
10. **如果失败了，能不能留下可迁移的结论？** 能 —— 「异构每序列内存（分页 KV + 非分页循环状态）下的分配与复用」这个抽象本身可迁移。

> 第 2 问的答案是「否」，因此**它对应的完成清单项不勾选**（如实反映），其余各项均满足。

## 存活清单

| 编号 | 一句话 | 进入条件（不满足即淘汰） | 为什么它不是伪问题（必须带量级或可复现证据） |

| **P2** | 状态检查点可用性与**调度路径**耦合（同一 token 前缀、不同批处理路径 ⇒ 不同命中） | **必须实测**命中率确实随路径变化，且排除口径伪影 | 证据是**本机源码的调度分支**（`v1/core/sched/scheduler.py:327`）+ `align` 的逐字语义（"每个 scheduler step 的最后一个 token"）——**可复现、非推测** |

**P4** 降为 P1 的旁证（本机可能不复现）；**P5** 保留为独立小课题（成本低但上界不明）；**P6 / P7** 淘汰。
