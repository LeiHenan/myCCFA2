## 完成清单

> 校验器逐条比对下面的文本；全部 `[x]` 才算该阶段完成。

- [ ] 观测量用**恒等式**定义（写成 `A = B − C` 或等价形式），不是『看起来相关的指标』
- [ ] 仪器经冒烟验证，并记下**单位/口径/计数器 vs gauge** 的核对结果
- [ ] 算出 **oracle 上界**的具体数字（完美决策能拿到多少），并写成百分比
- [ ] oracle 上界 ≥ 8%（低于此值立即杀，不要指望实验里变大）
- [ ] 噪声预算在**采数之前**估计（同配置重复、极差或置信区间），并写进判据
- [ ] 环境前提逐条列出（驱动/引擎版本/dtype/串行化开关/数据集必须真实文本等）
- [ ] 写出结论的**可采纳前置条件**（什么情况下这个测量无效，必须显式排除）

> **杀出口**：oracle 上界 < 8% ⇒ 杀（本仓库实证：T2 上界只有 +0.1%）；仪器口径未核 ⇒ 禁止采数
