# S5 预登记（子阶段续 2）— 新副本的语料获取策略（P 阶段）

**候选**：`sglang-draft-corpus` ｜ **时点**：2026-09-13 —— **数据采集前**（与 P 阶段脚本同 commit 冻结）
**母预登记**：`notes/prereg/sglang-draft-corpus.md`（`207de66` + 修订 `f4f8d70`）｜**R 阶段**：`notes/prereg/sglang-draft-corpus-r.md`（`3c590b4`）
**本文件按 E5 条款独立登记**：只回答"**新副本该从 0 学，还是从别处继承语料**"这一**策略问题**，
指标从"单次 accept"换成 **"整机总时间"**（母/R 阶段只测了热路径）。

## 主假设

> **H-P1（可行动的问题）**：在新副本上，**"用目标自己分布的语料预热"** 与 **"从别的租户继承语料"**，
> 单位收益所付的成本不同；存在一个可测的策略序，而不是"继承总是更好"。

> **H-P2（机制性预测，本轮最有信息量的一条）**：跨租户迁移**迁移不了长共享前缀**。
> 理由（源码）：trie 与 SAM 的匹配上下文都被 `max_trie_depth = 18` 截断
> （`ngram_worker.py:257-263` 注释 "Only the last max_trie_depth tokens can match"；
> `:296` 再用 `_efficient_concat_last_n(..., max_trie_depth)` 裁一次），
> 因此"共享 512-token 系统前缀"这一最常见的复用形态**落在窗口之外** ⇒
> **异租户源（只共享前缀）的收益应接近"仅 prompt 原文"，而不是接近"同分布源"**。

## 观测量与判据

**目标副本要服务的 workload** = `tenantB_prefix` 的 **32 条 prompt**（每条 = 512-token 共享前缀 + 4096-token 原文），
`temperature=0`、`ignore_eos=true`、`max_new_tokens=128`、**串行**、`--disable-radix-cache`。

| 量 | 定义 |
|---|---|
| `T_total` | **整机总时间** = 语料准备（生成那 N 条续写的 `e2e_latency` 之和，或恢复的墙钟）+ 目标 32 条请求的 `e2e_latency` 之和 |
| `accept` | 目标 32 条请求的 `spec_accept_length` 均值（**诊断量**，不是判据） |
| `cost_restore` | `POST /add_external_corpus` 墙钟 |

| # | 判据 | 阈值 |
|---|---|---|
| **P1** | 冷启动前提复现 | `accept(冷) ≤ 0.5 × accept(同分布源)` |
| **P2** | **异租户迁移 ≤3%** ⇒ H-P2 成立（前缀迁不动） | `accept(异租户源) ≤ 1.03 × accept(裸 prompt 源)` |
| **P3** | 文本型语料是否已够 | 若 `accept(原文源) ≥ 0.9 × accept(同分布源)` ⇒ 生成那一遍可省 |
| **P4** | 整机时间最优策略 | 报 `T_total` 最小值落在哪一臂；**并要求最优臂比"从 0 学"快 ≥8%** |
| **P5** | 口径自洽 | 全部行 `accept ≤ 8`、`rate ∈ [0,1]`、`cached_tokens == 0`，违例 0 |

## 网格（每臂 = 一个全新 serve 进程；同目标 workload；串行）

| 臂 | 新副本用的语料 | 语料准备成本 | 回答什么 |
|---|---|---|---|
| `S_cold` | 无（从 0 学） | 0 | 基线 |
| `S_self` | **目标分布自己的续写**（32 条 output） | 生成 32×128 tok | 上界（"副本自预热"） |
| `S_peer` | **异租户续写**（无前缀 prompt 的 32 条 output） | 生成 32×128 tok | **跨租户迁移能迁什么**（H-P2 主检验） |
| `S_text` | **目标 prompt 原文**（零生成） | 0（只需发送文本） | 文本是否已够（P3） |
| `S_bare` | 目标 **无前缀** 版本的续写（32 条） | 生成 32×128 tok | 隔离"前缀"这一因素 |

**固定量**：SGLang 0.5.19、Qwen3-4B、NGRAM γ=7、`sam_budget=7`、ctx 8192、`--max-running-requests 32`、
`mem-fraction-static 0.7`、串行、每臂独立进程、同一次实验内完成。

**逐轴"翻转会不会发生在极值处"论证**：

| 轴 | 范围 | 极值处会翻转吗 |
|---|---|---|
| 源↔目标重合度 | 完全相同（`S_self`）↔ 只共享 512-token 前缀（`S_peer`） | **翻转只可能发生在这两个极值之间**（`S_bare` 是"连前缀都不共享"的对照）⇒ 三点覆盖 |
| 前缀长度 | 512 token | **未测**其他长度；且按 H-P2，**任何 >18 token 的前缀都应表现相同**（被窗口截断）⇒ 512 足以检验该预测；更短的前缀（<18）会进入窗口，属**未测** |
| 语料形态 | 续写（output）↔ 原文（prompt 文本） | `S_self`/`S_peer`/`S_bare` 用续写，`S_text` 用原文 ⇒ 两形态都测 |
| 副本数 | 1 个新副本 | 多副本并发/网络传输**未测**（沿用 R 阶段的诚实边界） |
| 并发 | 串行 =1 | **未测**（沿用母预登记） |

## 杀判据

| 结果 | 处置 |
|---|---|
| **P1 不成立** | 本轮作废（前提失效） |
| **最优臂相对"从 0 学" < 8%** | **杀策略方向**：整机收益不够 ⇒ 本候选按 §1B 收口（不再主张策略贡献） |
| **P2 不成立**（异租户源明显优于裸 prompt 源） | H-P2 被否证 ⇒ **修正机制主张**（说明前缀确实能迁移，`max_trie_depth` 的截断不是决定性的），并把"前缀迁移"写成正面发现 |
| **P3 成立**（原文源 ≥0.9×同分布源） | 生成那一遍可省 ⇒ 策略退化为"发送文本"，**创新点进一步变薄** ⇒ 如实记录并降级 |
| `S_self` 未复现 ~6.7 | 本轮作废（与母阶段不一致） |

## 噪声与可分辨性

`temperature=0` + 固定种子 ⇒ 母/R 阶段实测 **σ = 0.0000**（逐位可复现）。本阶段判据用的是**时间**（秒级）与
**accept 的相对比**；`P2` 的 1% 阈值远宽于可分辨下限。**k = 3**（沿用）。

## 扩展条款

- **E-P1**：若 `P2` 成立（异租户迁不动）⇒ 追加**短前缀（8 token）**一臂，验证"前缀一旦进入 18-token 窗口就能迁移"这一**机制预测**。
- **E-P2**：若 `S_text ≥ 0.9 × S_self` ⇒ 追加"**只用前 18 个 token 对应的原文**"一臂，检验"窗口内的原文就够了"。
- **E-P3（明写不做）**：不做多副本并发继承、不做跨机传输、不做引擎内 trie 导出（无该接口，见 decision #105）。
