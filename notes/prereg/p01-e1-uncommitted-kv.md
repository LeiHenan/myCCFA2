| 项 | 内容 |
|---|---|
| **量** | `R = 未提交草稿 KV 字节 / 已提交 KV 字节`（逐步，报 p50 与 p95）；附峰值占用与占用时长 |

| **存活判据** | 存在 HBM 可行点 p95 ≥ 10% 且对应真实部署配置 ⇒ 进入机制设计 |
| **灰区** | 5% ≤ p95 < 10% ⇒ 不结论，先补测释放延迟与峰值占用 |
| **截止** | D1（1 天） |
| **不可外推** | 不得用"如果放得下"的配置外推；不得用 token 数占比代替字节占比 |

| **前置** | 无（`arXiv 2606.29223` 已于 2026-09-11 关闭） |
| **硬件条件分支** | 若用 24 GB 卡（4090/5090）：ctx 网格改为 **{4k, 16k, 32k}**，target 换 ≤4B，或用 2×24 GB 做 TP=2 以保留 128k 格。**此分支在任何数据采集之前登记（2026-09-11）**，不构成事后放宽 |
