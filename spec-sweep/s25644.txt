 Motivation
 Follow up on #21599 to support adaptive speculative decoding on the NPU backend.
 The adaptive speculative decoding path currently builds the target graph runner with CudaGraphRunner . This works for CUDA but does not correctly enable NPU graph execution. This PR adapts the runtime state construction and graph runner initialization so adaptive speculative decoding can run with NPU graph support.
 Related issue: #23705 
 Modifications
 Extend NPUGraphRunner to support adaptive speculative decoding parameters.
 Pass attn_backend , speculative_num_steps , and speculative_num_draft_tokens to the underlying graph runner initialization.
 Use NPUGraphRunner instead of CudaGraphRunner in adaptive runtime state construction when _is_npu is true.
 Apply the change to both EAGLE worker implementations: eagle_worker.py and eagle_worker_v2.py .
