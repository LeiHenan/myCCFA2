 Summary
 _speculative_sampling treats the returned candidate_logits as q , the
proposal distribution the draft tokens were drawn from. Three candidate
generators broke that contract, so with do_sample=True (and the default
 top_k=50 ) assisted decoding is not lossless as documented:
 Generator 
 Sampled from 
 Returned as q 
 DFlashTokenCandidateGenerator 
 processor-applied logits 
 raw logits 
 MTPCandidateGenerator ( MtpModel.forward ) 
 processor-applied logits 
 raw logits 
 SinglePositionMultiTokenCandidateGenerator 
 deterministic argmax 
 raw logits 
 With the mismatch, the acceptance ratio p_i/q_i is inflated by 1/Z (the
raw mass kept by top-k/top-p), and on rejection the [p - q]+ residual is
built from mass the drafter puts on tokens it can never propose.
 Changes
 candidate_generator.py — DFlashTokenCandidateGenerator stacks and
returns the processor-applied per-position logits; SinglePositionMultiTokenCandidateGenerator 
returns one-hot logits (point mass on the drafted token) describing its
deterministic argmax proposal.
 modeling_layers.py — MtpModel.forward returns the processed scores it
actually sampled from (raw logits preserved on the labels training path),
and binds next_token_scores on the no-processor path (fixes a latent
 UnboundLocalError when logits_processor / full_input_ids are None ).
 tests/generation/test_candidate_generator.py — new
 TestCandidateLogitsContract pinning returned == sampled-from for all
three generators (DFlash pinned-logits equality; MTP processed == warper(raw) 
with and without sampling; SinglePosition one-hot equality), all CPU-only.

 Speculative sampling treats the returned candidate logits as the proposal
distribution q, but DFlash and MTP sampled from processor-applied logits
while returning raw ones, and SinglePosition drafted deterministically
while returning raw logits. With do_sample=True and the default top_k=50
this broke the losslessness guarantee: acceptance ratios were inflated by
1/Z and the [p - q]+ residual was built from mass on unreachable tokens.
Fix the contract: DFlash returns the stacked processed logits, MtpModel
returns the processed scores it sampled from (also fixing an
UnboundLocalError on the no-processor path), and SinglePosition returns
one-hot logits describing its deterministic argmax proposal. Add contract
tests pinning returned == sampled-from for all three generators.
