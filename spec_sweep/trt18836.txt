 Description
 A one-engine speculative target LM head is COLUMN tensor-parallel, so SpecDecOneEngineForCausalLM.forward all-gathers its vocab shards into full-vocab logits and LogitsProcessor then upcasts that whole [tokens, vocab] tensor to fp32 — both proportional to the entire vocabulary, on every step.
 None of that is needed when the only consumer of the target logits is a greedy argmax. The argmax over the concatenated vocabulary equals the argmax of the per-rank (max, argmax) pairs rebased by tp_rank * vocab_per_rank , so it can be recovered by all-gathering two floats per row instead of the scores. The vocab-sharded draft head already does exactly this in greedy_sample_draft_with_tp_gather ; this PR factors that out into _greedy_argmax_over_vocab_shards and lets the target path reuse it.
 Gating
 The fast path is off unless the step provably qualifies:
 Head geometry ( _lm_head_shard_is_self_contained ): COLUMN TP, gather_output set, tp_size > 1 , and padding_size == 0 . Padding columns are only trimmed on the gathered path, so an unevenly divided vocabulary would otherwise leave a shard scoring token ids that do not exist.
 Worker opt-in ( can_verify_vocab_sharded_target_logits , False on the base class). Eagle3OneModelWorker returns True only with no guided decoder, no dynamic tree, no relaxed acceptance, no penalties, is_all_greedy_sample , and plain TP — every consumer that reads the logits' values rather than their argmax is excluded. Under attention DP the head is replicated and each rank owns different requests, so a cross-rank gather would desync the ranks; that is excluded too.
 lm_head.gather_output is flipped for the duration of the target head call and restored in a finally , the idiom Qwen3NextMTPHead.forward already uses for the draft head. LogitsProcessor.forward gains a keyword-only upcast_to_float: bool = True , so every existing caller is unchanged . spec_metadata.target_logits_vocab_sharded is written on every target forward, never left over from a step that took the other branch. The decision is logged once per outcome rather than per step.
 CUDA-graph-safe: is_all_greedy_sample is already part of the graph key, so the two branches land in separately captured graphs.
 Lossless: the widening bf16 → fp32 cast is exact and monotonic, so argmax(bf16) == argmax(fp32) ; the shards are contiguous and ordered by rank, so the first rank holding the maximum also holds its lowest global index and tie-breaking is preserved.
 Measured effect
 Serving Qwen3.6-35B-A3B-NVFP4 on 2×B200, attention TP2 + MoE EP2, ISL 1024 / OSL 6144, one-model MTP at draft length 2. Output throughput rises +5.04% on the mean of concurrency 64/128/256/512. An nsys diff over the same window (n = 47 iterations per side) puts the whole delta where the mechanism predicts:
 metric 
 delta 
 decode iteration 
 18.733 → 16.557 ms (−2.176, predicted −2.31) 
 … of which compute_busy 
 −1.361 ms (upcast + concat + argmax) 
 … of which occupied_not_computing 
 −0.823 ms (the all-gather) 
 device idle 
 +0.002 ms 
 So the freed time shortened the step rather than being re-absorbed. Kernel for kernel: the 863,585 ns all-gather collapses to 13,568 ns, the 981,730 ns upcast to 4,480 ns, the concat drops 243,361 → 4,768 ns, and the fp32 full-vocab argmax disappears entirely. The one row that grows is the bf16 shard max, which is what should grow.
 Trade-off, stated up front: the replacement collective is fixed per step while the work it removes scales with logits rows, so the balance inverts at the bottom of the band — concurrency 1 measured −3.31% and concurrency 4 −1.93% against the same baseline.
 Test Coverage
 New tests/unittest/_torch/speculative/test_vocab_sharded_target_logits.py (CPU-only, SimpleNamespace stand-ins with allgather stubbed by the rank-order concatenation it performs, mirroring test_group_all_greedy_sync.py ):
 Head geometry — the COLUMN/ gather_output / tp_size / padding_size precondition, including that a padded vocab and a non-TP or ROW-parallel head are all rejected.
 Worker gate — each excluded consumer closes it independently (guided decoder, dynamic tree, relaxed acceptance, non-greedy batch, penalties), as do tp_size == 1 and attention DP; and the base class does not opt in.
 Shard combine — the combined argmax equals a full-vocab argmax over random bf16 logits at TP2, reproduces argmax tie-breaking at TP4 over a value set small enough that the maximum repeats within and across shards, and argmax(bf16) == argmax(bf16.float()) .

 tensorrt_llm/_torch/speculative/interface.py

 tensorrt_llm/_torch/speculative/eagle3.py , tensorrt_llm/_torch/models/modeling_speculative.py , tensorrt_llm/_torch/modules/logits_processor.py 
 Eagle3 enables shard-local verification only for supported configurations. Speculative execution selects shard-local or gathered fp32 logits, logs each outcome once, and restores LM-head gather state. LogitsProcessor.forward conditionally upcasts logits.
