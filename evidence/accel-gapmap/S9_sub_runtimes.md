# S9 — Alternative runtimes / conversion pipelines (no training; PTQ / graph-compile only)

Scope: TensorRT-LLM (`trtllm-build`, `--use_paged_context_fmha`, PyTorch flow / `torch.compile`
with TRT backend, `trtllm-serve`), plain NVIDIA TensorRT via `torch_tensorrt` /
`torch.compile(backend="tensorrt")`, `torch.compile(mode="max-autotune"/"reduce-overhead")`,
ONNX Runtime / `onnxruntime-genai`, `llama.cpp` GGUF + `llama-quantize`, `mlx` (context only),
`exllamav2`/EXL2, AutoAWQ, standalone Marlin and AWQ kernels.

Target rig for relevance: ONE GPU, RTX PRO 6000 Blackwell 96 GB, **sm120** (CC 12.0; sm120 is NOT
sm100), driver 580, 208 CPU cores, single node, no NVLink/IB/cluster; vLLM 0.29.0, SGLang 0.5.19;
model Qwen3-4B dense full-attention.

Date of all retrievals in this file: 2026-09-13 (site "last updated" stamps noted where the page
carried one).
