Researcher E5. Axes: `batching_sched`, `sampling_logits`, `tokenizer_detok`, `host_cpu_overhead`,
`serve_api`, `longctx_attn` (attention only, not KV-cache policy), `memory_alloc`.
Target rig for relevance: ONE RTX PRO 6000 Blackwell (96 GB, **sm120**, driver 580, no NVLink, no
cluster), SGLang 0.5.19, **Qwen3-4B dense / full attention**, drafters dflash2 + EAGLE3,
heavily **host-bound at low batch**.

Method: every row starts from a verbatim engine self-admission in the installed source tree
(`/tmp/sglang-main/python`, used only for corroboration — all URLs below are GitHub). For each
claim I ran the never-discussed test: repo-scoped GitHub issue/PR search (all states, title+body+
comments) on `sgl-project/sglang`, `vllm-project/vllm`, `pytorch/pytorch`, plus `web_search` and
arXiv. `github.com/search` returns HTTP 429 from this environment; repo-scoped
`/{owner}/{repo}/issues?q=` and `/pulls?q=` return 200 and were used instead.

`## DISCUSSED (therefore NOT Section E)` and are not Section E rows. Two early candidates
