Code Review

 This pull request introduces the NVFP4ExpandedMSEObserver and adds support for range expansion and global scale priors in the MSE observers to improve NVFP4 quantization quality. It also includes an example script demonstrating this quantization configuration on Llama 3. Feedback highlights a potential runtime error in _compute_approx_global_scale due to missing weight attributes or device mismatches, as well as potential unexpected behavior in the expansion logic when applied to asymmetric quantization with positive-only or negative-only tensors.

--- COMMENT 3 ---
If mod does not have a weight attribute (or if weight is None ), accessing mod.weight will raise an AttributeError or TypeError . Furthermore, if mod.weight is on a different device than observed (for example, if weights are offloaded to CPU during calibration while activations/observed tensors are on GPU), torch.max will raise a device mismatch RuntimeError .

 We should safely check for the existence of weight and cast the tensor to the correct device before computing the maximum.
