--- COMMENT 1 ---
**Description:**

Currently, there are no direct download links to already optimized models. Having to run TensorRT Model Optimizer myself adds extra steps and, in most cases, does not work reliably.

It would be very helpful if you could provide **downloadable, pre-optimized models** for SM120 Blackwell with quantization formats such as **FP8** and **NVFP4**.

**Why this is needed:**

* Running optimization locally is fragile and often fails.
* Many users just want ready-to-run optimized checkpoints instead of debugging optimization pipelines.
* Providing pre-optimized models would save time and help ensure consistent performance.

**Examples tried but not working:**

* `daslab-testing/Llama-3.2-3B-Instruct-FPQuant-QAT-NVFP4-200steps`
* `nm-testing/TinyLlama-1.1B-Chat-v1.0-NVFP4-Updated`
* `nm-testing/Llama-3.1-8B-Instruct-NVFP4A16`

**Request:**

* Please provide **download links** to FP8 and NVFP4 quantized models that run on **SM120 Blackwell GPUs**.

This would significantly improve usability and adoption for those of us testing or deploying on Blackwell hardware.


TensorRT-LLM Docker Image: nvcr.io/nvidia/tensorrt-llm/release:1.1.0rc1

--- COMMENT 2 ---
Pre-optimized model checkpoints are available [here](https://huggingface.co/collections/nvidia/inference-optimized-checkpoints-with-model-optimizer), please try them out on blackwell gpus.
Are you looking for `Llama-3.2-3B-Instruct`, `TinyLlama-1.1B-Chat-v1.0` and `Llama-3.1-8B-Instruct` specifically?

--- COMMENT 3 ---
@i-riyad thanks - I wanted to benchmark smaller models to see how NVFP4 impacts tokens/sec. I’m currently testing on a 5060 Ti 16GB with tp=1/2.

Any widely available model with all quant formats (NVFP4, FP8, BF16) would work, ideally across sizes like 1B / 4B / 8B for comparison.

Benchmark is not just for speed but quality as well.

The hf model collection contains quantised versions of only larger models, not suitable for above goal.

--- COMMENT 4 ---
@rnik12, we do not have any plans as of now to release checkpoints for smaller models. We encourage developers to create the quantized checkpoints themselves given the smaller sizes. If you encounter a specific problem while optimizing these models, please open a new issue. We will help resolve it.
