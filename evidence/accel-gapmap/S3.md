### B1.1 | OPEN
WHO IS STILL ASKING: christianbalbin (vLLM issue author) — re-opened after a stale-bot pass; RFC #18153 "Blackwell Enablement for vLLM (SM100)" is the tracking context
URL: https://github.com/vllm-project/vllm/issues/35439
ASKING QUOTE: "The existing W4A8 kernels (Cutlass, Machete) use Hopper-specific wgmma PTX
  instructions that don't carry forward to SM100. This isn't a version check
  oversight — SM100 needs its own kernel implementations. W4A16 works on
  Blackwell via Marlin because those kernels use more portable instruction paths."
WHAT IS MISSING: There is no W4A8 (INT4 weight x FP8/INT8 activation) kernel for any Blackwell part,
sm120 included. In vLLM 0.29.0 the only W4A8 paths are `CutlassW4A8LinearKernel` and Machete, and
both are gated at capability 90 (the issue quotes the loader error verbatim:
"CutlassW4A8LinearKernel cannot implement due to: CUTLASS W4A8 requires compute capability of 90 (Hopper)");
llm-compressor's own W4A8 doc says the acceleration is on Arm CPUs via KleidiAI; TensorRT-LLM marks
