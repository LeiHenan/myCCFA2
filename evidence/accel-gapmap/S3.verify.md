## Confirmations (rows I checked and could not falsify)

### The known-thin claim: "INT8 W8A8 is hard-blocked on sm120 by design"

**A1.3 — CONFIRMED, and stronger than the row states.** All three vLLM sources re-locate:

1. `docs/features/quantization/llm_compressor/int8_w8a8.md` (main) → `MATCH` (ratio 1.0), including
   `**Blackwell GPU Limitation**: INT8 is not supported on compute capability >= 10.0 (e.g., RTX 6000 Blackwell).`
2. `csrc/libtorch_stable/quantization/w8a8/cutlass/scaled_mm_c3x_sm120.cu` → `nullptr,  // int8 not supported on SM120` ✔
   (also present in the local mirror `/tmp/vllm-0.29.0`).
3. `csrc/…/c3x/scaled_mm_helper.hpp` → `STD_TORCH_CHECK(false, "Int8 not supported on SM", version_num, ". Use FP8 quantization instead, or run on older arch (SM < 100).");` ✔

I then tried to falsify the *block* itself, because a hard block would normally be escaped by a
different kernel family. It is not:

- `scaled_mm_entry.cu` dispatches `version_num >= 120` → `cutlass_scaled_mm_sm120(...)` **unconditionally,
  before** the sm100/sm90/sm80 branches and with no dtype test, so an INT8 `a` reaching the op on sm120
  lands in the `nullptr` slot and raises.
- `vllm/model_executor/kernels/linear/scaled_mm/cutlass.py::CutlassInt8ScaledMMLinearKernel.is_supported`
  returns `(True, None)` for **any** CUDA capability and `can_implement` returns `(True, None)` — it does
  **not** exclude CC ≥ 10.
- `vllm/model_executor/kernels/linear/__init__.py::_POSSIBLE_INT8_KERNELS[PlatformEnum.CUDA]` is
  `[CutlassInt8ScaledMMLinearKernel, TritonInt8ScaledMMLinearKernel, HummingInt8ScaledMMLinearKernel]`,
  and `init_int8_linear_kernel()` passes no `compute_capability`, so the CUTLASS kernel always wins the
  race. The Triton INT8 kernel (`triton_scaled_mm`, which *would* run on sm120) is therefore never
  reached — the block is real and unavoidable through the supported path, exactly as claimed.
- The arXiv fourth source is real: **2608.11693 → "Spec Sheets Are Not Kernels: An ISA- and Source-Level
  Audit of INT8 Availability on NVIDIA Blackwell Ultra"** ✔ (title matches the row's characterisation,
  including that it targets Blackwell Ultra / sm_103a rather than sm120).
