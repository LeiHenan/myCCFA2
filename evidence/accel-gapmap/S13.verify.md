- `verify.py quote` returns MISMATCH for quotes that contain Markdown link syntax (D.4.1–D.4.3) because its

  `CMakeLists.txt` this deletes ~14 KB of the file. This is a checker limitation, not a row defect, and it
  is why the exactness number below is computed against the **raw** file text for raw URLs.
