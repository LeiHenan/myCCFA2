### CLOSED-5: Cross-process KV cache key determinism (dedup across instances)
- URL: https://github.com/vllm-project/vllm/blob/main/docs/features/kv_offloading_usage.md
- Evidence: READ BODY
- Detail: Verbatim: "KV cache sharing between multiple vLLM instances using the same `root_dir` (e.g., via a shared PVC) works by default: `NONE_HASH` (the chain-hash seed for block content hashes) is derived from a fixed default seed, so identical token content produces identical block filenames across instances.
