RunLLM April 25, 2025, 6:42am 2

The low acceptance rate you are experiencing with EAGLE in vLLM could be due to several factors. According to the vLLM documentation, the EAGLE-based draft models need to be run without tensor parallelism, which you have correctly set with --speculative_draft_tensor_parallel_size=1. However, the acceptance rate can also be influenced by the compatibility and tuning of the draft model with the target model, as well as the specific dataset or prompt being used.

Additionally, the EAGLE implementation in vLLM is known to have a lower observed speedup compared to the reference implementation by SafeAILab. This discrepancy is under investigation, and it might be affecting the acceptance rate. You might want to experiment with different speculative token numbers or adjust the temperature setting to see if it improves the acceptance rate. If the issue persists, consider checking for updates or discussions on the vLLM GitHub repository for any ongoing improvements or fixes related to EAGLE.
