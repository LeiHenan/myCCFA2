 Abstract
 Speculative decoding accelerates large language model inference by drafting multiple candidate tokens and verifying them in a single forward pass.
Candidates are organized as a tree: deeper trees accept more tokens per step, but adding depth requires sacrificing breadth (fallback options) under a fixed verification budget.
Existing training-free methods draft from a single token source and shape their trees without distinguishing candidate quality across origins.
We observe that two common training-free token sources— n n -gram matches copied from the input context, and statistical predictions from prior forward passes—differ sharply in acceptance rate ( ∼ 6 × {\sim}6\times median gap, range 2 2 – 18 × 18\times across five models and five benchmarks).
We prove that when such a quality gap exists, the optimal tree is anisotropic (asymmetric): reliable tokens should form a deep chain while unreliable tokens spread as wide branches, raising the depth ceiling of balanced trees.
We realize this structure in Goose , a training-free framework that builds an adaptive spine tree —a deep chain of high-acceptance context-matched tokens with wide branches of low-acceptance alternatives at each node.
The resulting tree provably accepts at least as many tokens per step as either source alone.
On five LLMs (7B–33B) and five benchmarks, Goose achieves 1.9 1.9 – 4.3 × 4.3\times lossless speedup, outperforming balanced-tree baselines by 12 12 – 33 % 33\% under the same budget.
 1 Introduction
 Speculative decoding  ( Leviathan et al., 2023 ; Chen et al., 2023 ) accelerates autoregressive LLM inference by letting a drafter propose several candidate tokens at once.
The target model verifies them in a single forward pass, accepting correct guesses at no extra cost while keeping the output provably identical to standard decoding ( lossless ;  Leviathan et al., 2023 ).
 The simplest draft is a single chain : efficient when the drafter is accurate, but a single rejection loses the entire continuation.
 Tree-structured speculation   ( Miao et al., 2024 ; Cai et al., 2024 ) hedges this risk with multiple candidates organized as a tree, whose tree attention mask restricts each candidate’s attention to its ancestors so the target model scores every root-to-leaf path in one forward pass.
Designing a good draft tree then means allocating a fixed node budget  B B between depth (longer paths) and breadth (more fallbacks).
 Among training-free methods, three representative approaches illustrate the design space and its limits.
 Token Recycling  ( TR ;  Luo et al., 2025 ) retrieves statistically likely next tokens from the target model’s own logits, producing wide, shallow trees that hedge broadly but sacrifice depth.
 Prompt Lookup Decoding  ( PLD ;  Saxena, 2023 ) copies n n -gram-matched continuations from the input context, producing a deep chain accepted at high rates, but with no fallback when the match breaks or is absent.
Sequoia  ( Chen et al., 2024 ) optimizes the depth–breadth trade-off by dynamic programming, but under a source-blind acceptance model: acceptance depends on a candidate’s rank among siblings, not on its provenance.
Such a model cannot favor high-acceptance tokens when sources of different reliability coexist.
 This source-blind assumption forfeits a key structural advantage once both sources coexist.
We measure that context-matched ( PLD ) tokens are accepted 2 2 – 18 × 18\times more often than transition ( TR ) tokens (median  ∼ 6 × {\sim}6\times across five models and five benchmarks; Section   3 ).
This acceptance heterogeneity suggests placing high-acceptance tokens along a deep spine and low-acceptance tokens as wide branches at every spine node: the spine pushes depth while branches provide fallback when it breaks early.
We instantiate this insight in Goose , a training-free framework that builds an adaptive spine tree ( Figure   2 ): a deep chain of context-matched tokens, with wide branches of transition alternatives forking from every spine node, verified by a unified greedy walk in one forward pass.
We prove that the spine tree’s expected yield (accepted tokens per cycle) is at least that of either source used alone ( Proposition   4 ), and design runtime adaptations that preserve this property when one source is absent or dominant ( Section   4.3 ).
 Our contributions:
 1. 
 We formalize acceptance heterogeneity between two training-free token sources and prove that the optimal tree is anisotropic , allocating depth to reliable tokens and breadth to unreliable ones, which raises the depth ceiling of single-source trees ( Section   3 ).
 2. 
 We design a confidence-adaptive, training-free tree construction that combines PLD and TR into a single spine tree with a non-degradation guarantee on expected yield ( Figure   3 ).
 3. 
 Experiments on five models (7B–33B) across five benchmarks show 1.9 1.9 – 4.3 × 4.3\times lossless speedup, outperforming isotropic-tree baselines by 12 12 – 33 % 33\% under equal node budgets ( Table   2 ).
 2 Related Work
 Speculative decoding  ( Leviathan et al., 2023 ; Chen et al., 2023 ; Stern et al., 2018 ) accelerates autoregressive LLM inference by guessing multiple future tokens and verifying them in a single forward pass; Xia et al. (2024) provide a comprehensive survey.
A key extension is tree-structured verification   ( Miao et al., 2024 ; Cai et al., 2024 ) : candidates are organized into a tree and checked simultaneously, after which the longest accepted path is selected and one bonus token is appended.
 Draft-model methods.
 Representative approaches include EAGLE  ( Li et al., 2024b ; Li et al., 2024a ) , which trains feature-level draft heads, and Medusa  ( Cai et al., 2024 ) , which attaches parallel prediction heads; EAGLE-3  ( Li et al., 2025 ) replaces feature prediction with direct token prediction and multi-layer feature fusion, achieving up to ∼ 6.5 × {\sim}6.5\times speedup.
All such methods  ( Miao et al., 2024 ; Kim et al., 2023 ; Zhou et al., 2024 , inter alia ) require per-model training or auxiliary models, limiting deployment flexibility.
 Training-free methods.
 Training-free drafters avoid auxiliary models entirely by mining candidate tokens from data already available at inference time.
The simplest strategy copies tokens from reference documents  ( Yang et al., 2023 ) or from the prompt and prior output via n n -gram matching  ( Saxena, 2023 ) ; such copies are cheap but limited to recurring patterns.
A broader class retrieves candidates from external datastores—REST  ( He et al., 2024 ) uses a suffix array, SuffixDecoding  ( Oliaro et al., 2025 ) a suffix tree over the prompt and prior outputs (compared head-to-head in Section   5.2 ), while Lookahead Decoding  ( Fu et al., 2024 ) constructs n n -grams on the fly through parallel Jacobi iterations.
Other methods refine token selection  ( Somasundaram et al., 2025 ; Le et al., 2025 ) or reuse the model’s own early layers  ( Zhang et al., 2024 ; Elhoushi et al., 2024 ) .
All the above improve which tokens to draft .
 Goose asks the orthogonal question of how the verification tree should be shaped given sources with very different acceptance rates; better token selection would only widen the gap the spine tree exploits.
 Tree topology optimization.
 Sequoia  ( Chen et al., 2024 ) formalizes the depth–breadth trade-off introduced above: under its positional acceptance assumption , acceptance depends only on a token’s rank among siblings, so its DP produces non-uniform trees while remaining source -blind—one acceptance vector for all candidates.
We call a balanced tree with the same branching at every depth isotropic and use it as our equal-budget topology control ( Section   5.3 ); we additionally compare against Sequoia’s official DP-optimized trees in Section   5.2 .
 EAGLE-2  ( Li et al., 2024a ) prunes low-confidence branches via the draft head’s per-token scores, growing deeper along well-predicted paths; this adapts the shape to within-drafter quality variation but requires a trained head and lacks optimality guarantees.
 TR   ( Luo et al., 2025 ) applies a similar principle within its transition lookup table: higher-ranked candidates receive more children than lower-ranked ones, producing non-uniform trees without training.
 Despite producing non-uniform trees, these methods optimize within a single draft source, so the quality differences they exploit remain within-source .
 Goose exploits a qualitatively different axis: the cross-source gap between context-matched and transition tokens ( 2 2 – 18 × 18\times ; Section   3 ).
Extending Sequoia’s DP to this heterogeneous setting yields an anisotropic optimum, in which reliable tokens form a deep chain while unreliable ones spread as wide branches, confirmed by 12–33% gains ( Table   2 ).
 3 Optimal Topology under Heterogeneous Acceptance
 The optimal tree shape follows directly from the acceptance asymmetry between the two draft sources.
We build on Sequoia’s framework  ( Chen et al., 2024 ) , which models each draft token as independently accepted with a source-independent probability and optimizes the tree via dynamic programming; we extend the model to two sources with different acceptance rates.
This section formalizes that asymmetry, derives the expected yield of the spine tree ( Proposition   1 ), proves that branches should be concentrated near the root ( Proposition   2 ), and shows that the resulting tree strictly dominates any single-source alternative ( Proposition   3 ).

 p s p_{s} for context-matched ( s pine) tokens and p t p_{t} for t ransition tokens, with p s > p t p_{s}>p_{t} .
Each spine token is modeled as independently accepted with probability  p s p_{s} .

 Remark (i.i.d. as a modeling approximation).
 The i.i.d. acceptance model in Propositions  1 – 3 is a modeling approximation , and it enters only the theoretical analysis, not the measurements: the headline 12 12 – 33 % 33\% anisotropic-vs-isotropic gain ( Table   2 ) is a direct equal-budget measurement that assumes no acceptance law.
Positive intra-chain correlation, if anything, makes the modeled allocation conservative; empirical gains in Table   2 confirm the model captures the dominant qualitative structure ( Section   E.4 ).
Empirically, acceptance decay over depth is fit better by a geometric law ( R 2 = 0.77 R^{2}{=}0.77 vs. 0.69 0.69 ; Qwen3-8B traces, ≈ 0.5 {\approx}0.5 M tree nodes per depth), whereas the all-reject frequency as a function of branch width is fit better by a power law (Llama-3 traces, Section   E.5 ; with a selection-effect caveat).
In Section   E.6 we re-derive the optimal allocation under that empirically-fit tail ( α ^ = 0.261 \widehat{\alpha}{=}0.261 ) and show the optimum keeps the same root-concentrated anisotropic shape; our deployed harmonic schedule is more conservative than either optimum at the root while retaining residual depth-side breadth.

 Goose follows the standard speculative-decoding loop  ( Cai et al., 2024 ) —generate candidates, verify them in one forward pass, accept the longest correct path—but reshapes the candidate tree into a single asymmetric structure that combines two complementary token sources ( Figure   2 d).
Each decoding cycle begins from an anchor token , the last token accepted in the previous cycle, and proceeds in three stages ( Figure   3 ).
 Stage 1—Build spine tree. 
 Goose assembles a candidate pool from two sources.
Context matching ( PLD ) retrieves a continuation from previously generated text, forming a deep chain called the spine .
The adjacency table , our bigram extension of TR ’s adjacency matrix ( Section   4.1 ; implementation in Section   C.1 ), supplies statistically likely alternatives that fork from spine nodes as branches .
 BuildSpineTree allocates the node budget  B B between spine and branches ( Section   4.1 ), then packs all candidates into one sequence with a tree attention mask : a modified causal mask that lets each node attend only to its root-to-node ancestors, so all paths are verified in one forward pass.
 Stage 2—Verify and harvest. 
One LLM forward pass scores every candidate.
All logits—including those at rejected branches—are harvested into the adjacency table, and the accepted prefix updates the PLD context index, enriching both sources for future cycles.
 Stage 3—Select longest correct path. 
A greedy walk identifies the longest path verified as correct by the target model ( Section   4.2 ); the last accepted token becomes the anchor of the next cycle.
 The tree shape is not fixed.
When context-match confidence is high, Goose skips tree construction and verifies the PLD chain linearly ( bypass mode ; Section   4.3 ); when no context match exists, the spine vanishes and the full budget forms a TR -only tree.
The asymmetric topology enables a synergy we call spine continuation : when a mismatch occurs on the spine, a branch at that point can extend the accepted path, recovering tokens that neither source alone would have found.
 Two refinements improve candidate quality (ablated in Table   2 ): agreement among n n -gram lengths on the first token is treated as high confidence and extends the spine aggressively, and the adjacency table uses bigram rather than unigram conditioning to sharpen branch predictions.
The complete decode loop is in Algorithm   2 (Appendix).
 4.1 Spine Tree Construction
 Tree construction.
 Given the anchor token and node budget  B B , one parameter controls the budget split: the spine ratio   r r , which sets what fraction of  B B goes to spine nodes (adapted online; Section   4.3 ).
Construction proceeds in four steps ( Algorithm   1 , Appendix):
(1) lay the spine—allocate up to B ⋅ r B{\cdot}r nodes as a linear chain of context-matched tokens;
(2) add root branches—attach the top adjacency-table alternatives at the root, using a share ( 1 − ρ ) (1{-}\rho) of the remaining budget (spine-branch ratio ρ = 0.5 \rho{=}0.5 by default);
(3) add spine branches—distribute the remaining share  ρ \rho across spine nodes, with wider branches near the root and narrower ones deeper, approximating the optimal allocation derived in Proposition   2 ;
(4) extend all branches recursively via the adjacency table up to a maximum depth of 6.
As introduced above, the adjacency table conditions on the two most recent tokens rather than TR ’s original single-token lookup  ( Luo et al., 2025 ) , improving prediction accuracy.
 4.2 Unified Verification and Non-Degradation
 The spine tree implicitly contains all candidate paths; verification requires only a single greedy walk.
 Greedy walk with source priority.
 Starting at the root, the walk advances to a child whose draft token equals the target model’s greedy argmax at the current node—pure token-identity matching, with no per-token score gate : draft-side scores ( TR adjacency counts, PLD match length) are used only at construction time and are never consulted during verification, and no acceptance probability is carried from parent to child.
At each node the walk checks the PLD (spine) child before the TR (branch) children; duplicates are excluded, so at most one child can match and the priority never changes the accepted path; once the walk leaves the spine for a branch it does not return ( Section   B.3 ).
The walk terminates when no child matches, and the accepted path falls into one of three categories:
(a)  Pure PLD (all spine nodes, equivalent to standalone context-match),
(b)  Spine continuation (spine followed by a TR branch at the mismatch point—the synergy unique to the spine tree), or
(c)  Pure TR (root branch only, equivalent to standalone transition).
No multi-path bookkeeping is needed; the greedy walk automatically discovers the longest accepted path.
At termination, the target model samples one additional bonus token from its distribution at the last accepted position, following the standard speculative-decoding guarantee  ( Leviathan et al., 2023 ) .
 Proposition 4 (Non-Degradation Guarantee) . 
 For any node budget  B B , the spine tree’s expected yield —the expected number of tokens accepted per cycle—is at least as large as that of standalone context matching or standalone transition-tree decoding, each given the full budget  B B . 
 Proof sketch. 
(i) Standalone PLD yields a chain bounded by the match length, not  B B ; Goose preserves those tokens in full (short matches fit within ⌊ B ​ r ⌋ \lfloor Br\rfloor ; long matches trigger bypass, Section   4.3 ) and fills the unused budget with branches, so its accepted path is at least as long.
(ii) Versus a standalone transition tree, the spine swaps breadth nodes for higher-acceptance context-matched depth, which can only maintain or increase expected path length ( Proposition   3 ); with no context match, the spine vanishes and the transition tree is recovered exactly. □ \square 
 Remark. 
The guarantee holds for expected yield, not directly wall-clock, and parts (i)/(ii) rely on the runtime adaptations of Section   4.3 (minimum spine ratio, bypass, graceful fallback) for the boundary cases a fixed shape cannot cover; Table   2 quantifies their contributions.
 The greedy walk is formalized in Algorithm   3 ; the full decoding loop, including tree construction and logit harvesting, is in Algorithm   2 (Appendix).
 4.3 Confidence-Adaptive Topology
 Not every cycle benefits equally from tree construction.
 Goose uses a continuous PLD confidence signal to modulate tree shape, ranging from a full spine tree down to a simple linear chain.
 Confidence signal.
 Goose queries context matching with multiple n n -gram lengths { 3 , 4 , 5 } \{3,4,5\} .
Confidence is a function of two indicators: (i)  consensus —at least two n n -gram lengths return continuations that agree on the first token, and (ii)  chain length —long matches (8 or more tokens) indicate high PLD acceptance.
When confidence is high, tree construction is skipped and the spine is verified as a single linear sequence ( bypass mode), preserving the guarantee of Proposition   4 .
The spine ratio  r r is adjusted each cycle by an EMA of the PLD acceptance rate: high averages deepen the spine ( r → 0.50 r\to 0.50 ), low ones shift budget to branches ( r → 0.15 r\to 0.15 ), converging within 3–5 cycles (details in Section   C.3 ).
 5 Experiments
 5.1 Setup
 Models, hardware, and datasets.
 We evaluate five instruction-tuned models spanning 7B–33B parameters: Vicuna-7B/13B/33B  ( Zheng et al., 2023 ) , Llama-3-8B-Instruct  ( Meta AI, 2024 ) , and Qwen3-8B  ( Qwen Team, 2025 ) , all in FP16. The 7B–13B models run on a single NVIDIA A40 (48 GB); Vicuna-33B runs on 2 × \times A100-40GB.
We evaluate on five benchmarks spanning code, math, and dialogue:
HumanEval  ( Chen et al., 2021 ) , MBPP  ( Austin et al., 2021 ) , ClassEval  ( Du et al., 2023 ) , GSM8K  ( Cobbe et al., 2021 ) , and MT-Bench  ( Zheng et al., 2023 ) —ranging from high repetition (code templates) to low repetition (open dialogue).
Dataset sizes and generation lengths are listed in Table   4 .

 Baselines and metrics.
 AR (standard autoregressive), standalone PLD   ( Saxena, 2023 ) , standalone TR   ( Luo et al., 2025 ) (using its default imbalanced BFS tree with unigram adjacency), Lookahead Decoding  ( Fu et al., 2024 ) , REST  ( He et al., 2024 ) , and EAGLE-2  ( Li et al., 2024a ) (draft-head method; Vicuna-7B, Llama-3-8B, Vicuna-13B, and Vicuna-33B using official released heads).
For the topology comparison ( Section   5.3 ), we evaluate Isotropic ( k k ): a balanced k k -ary tree with k ∈ { 3 , 5 } k\in\{3,5\} and the same node budget, using Goose ’s draft source.
This baseline is a topology control (uniform shape at equal budget), not a reproduction of Sequoia, whose DP builds non-uniform trees  ( Chen et al., 2024 ) ; we compare against its official implementation in Section   5.2 .
All methods use greedy decoding and produce identical output (lossless).
We additionally compare with EAGLE-3  ( Li et al., 2025 ) in Section   5.2 ; its drafter is a single decoder layer plus an FC fusion layer, comparable in scale to EAGLE-2’s head.
We report τ \tau (compression ratio: mean tokens accepted per verification call; cf. Section   3 ), tok/s (wall-clock throughput), and Speedup (tok/s vs. AR); all hyperparameters are fixed across datasets and models (node budget B = 60 B{=}60 , max branch depth D = 6 D{=}6 , top- K = 10 K{=}10 adjacency candidates, spine-branch ratio ρ = 0.5 \rho{=}0.5 ; full list in Section   C.3 ).
During the first few cycles, the adjacency table is empty; Goose gracefully degrades to pure PLD (or AR if no context match exists) and populates the table from the resulting logits.
 5.2 Main Results

All methods are lossless (greedy decoding, identical output); Goose values are annotated above each group and the sixth panel is the per-model mean.  Figure   4 summarizes the main results.
 Goose achieves 1.9–4.3 × \times lossless speedup across all five models, consistently outperforming every training-free baseline.
Speedup varies predictably with acceptance heterogeneity:
ClassEval (repetitive templates) yields up to 4.3 × \times ; MT-Bench (open dialogue) still reaches 1.9–2.9 × \times , confirming that TR branches alone contribute meaningful acceleration.
One outlier: on Llama-3-8B GSM8K, near-verbatim repetition inflates speedup to 7.5 × \times ( τ = 9.25 \tau{=}9.25 ); all other 24 settings fall within the 1.9–4.3 × \times speedup range.
 Comparison with EAGLE-2.
 EAGLE-2’s trained draft head yields higher τ \tau ( Table   3 ), but its per-step latency offsets the advantage: Goose outperforms EAGLE-2 on Llama-3-8B (4.1 × \times vs. 2.4 × \times ), matches on Vicuna-7B (2.9 × \times vs. 2.9 × \times ), while EAGLE-2 leads on Vicuna-13B (2.8 × \times vs. 3.3 × \times ) and Vicuna-33B (2.4 × \times vs. 3.2 × \times ).
Two factors explain this pattern.
 Model size sets the wall-clock winner : at ≤ 8 {\leq}8 B the base forward is cheap, so zero drafter cost outweighs EAGLE’s higher τ \tau ; at ≥ 13 {\geq}13 B the slower base forward lets that higher τ \tau convert and win.
 Task repetition sets the margin : the spine fires most on repetitive workloads and least on open-ended dialogue.
We read this as an empirical trend on these models, not a strict size law.
As a training-free method, Goose also covers models for which no trained draft head exists (Qwen3-8B).
 Comparison with stronger baselines.
 Three further systems bracket the strongest alternatives; SuffixDecoding and Sequoia also appear in Table   3 .
SuffixDecoding  ( Oliaro et al., 2025 ) , the strongest training-free drafter reported in prior work, drafts from a suffix tree over the prompt and prior outputs—richer statistics than Goose ’s bigram adjacency table.
At full scale (6 models × \times 13 datasets), Goose leads τ \tau in all 78 cells and wall-clock throughput in all 52 cells with full accounting (geometric mean + 35 +35 – 36 % 36\% ); per-cycle instrumentation attributes the gap mainly to depth allocation— Goose speculates 52–60 nodes per non-dry cycle at depths 5.7 5.7 – 22 22 , against SuffixDecoding’s 3–8 at 2.9 2.9 – 7.3 7.3 —with coverage (twice as many dry cycles, whose draft is empty or a single token) and cold start second, and merging its two trees into one does not close it ( Section   D.8 ).
Conversely, swapping our PLD spine for that suffix tree raises τ \tau in all 15 cells tested ( + 3 +3 – 47 % 47\% , Section   D.6 ), so the topology is agnostic to which source feeds the spine.
Sequoia  ( Chen et al., 2024 ) optimizes tree shape under a single acceptance vector: we reproduce its published τ \tau within ± 6 % \pm 6\% on its released Llama-2-7B stack, where its trained 68M drafter wins τ \tau on all three of its datasets yet the two systems trade wall-clock ( Goose + 8 % +8\% on C4, Sequoia + 5 % +5\% on CNN/DM, OpenWebText within noise). Its per-cycle drafter forward decides the outcome and costs more at modern scale: there Sequoia reaches τ \tau of 6.2 6.2 – 9.2 9.2 yet never exceeds 1.60 × 1.60\times wall-clock, and on Qwen3-8B it drops below AR outright ( Section   D.9 ).
EAGLE-3  ( Li et al., 2025 ) is the strongest trained drafter.
Its head is trained on chat-template data, so the chat-template protocol is its fair setting; there it wins 4 of 5 datasets ( + 53 +53 – 79 % 79\% tok/s, with Goose retaining ClassEval at + 39 % +39\% ).
Under our raw-prompt protocol the result inverts and Goose leads all five ( + 25 +25 – 83 % 83\% on the four non-truncated datasets; Section   D.4 ).
We do not claim to beat EAGLE-3 in its native setting; the two are cross-category ( Section   6 ).

 5.4 Analysis
 Source decomposition and synergy.
 Figure   5 a decomposes each model’s mean  τ \tau into the best standalone baseline max ⁡ ( τ PLD , τ TR ) \max(\tau_{\textsc{PLD}{}},\tau_{\textsc{TR}{}}) and the synergy gain from the spine-tree topology.
The synergy ratio ( τ Goose / max ⁡ ( τ PLD , τ TR ) \tau_{\textsc{Goose}{}}/\max(\tau_{\textsc{PLD}},\tau_{\textsc{TR}}) ) exceeds 1.0 on all 25 settings (average 1.24 × \times ; per-model breakdown in Section   D.1 ).
The source split varies by task; even on the weakest datasets, every A40 cell stays above 2.6 × 2.6\times τ \tau ( Section   D.2 ).
A per-accept source attribution across four models confirms the sources are complementary: PLD ’s share spans 33–85% by task, and where it is sparsest TR supplies the majority without τ \tau collapsing ( Section   D.5 ).
Tree construction adds negligible CPU overhead ( < < 1% of wall-clock time).
 Goose has no neural drafter: the draft comes from table lookup, and the only model call per cycle is the verification forward.
This makes the conversion from τ \tau to wall-clock tight.
On Llama-3-8B HumanEval, τ = 4.11 \tau{=}4.11 yields a measured 3.36 × 3.36\times speedup, a ≈ 82 % {\approx}82\% conversion; the shortfall is tree construction plus the slightly larger, weight-bound verification forward.
 6 Discussion and Conclusion
 We introduced the spine tree, an anisotropic draft-tree topology that exploits acceptance heterogeneity among training-free draft sources.
Without any training, Goose achieves 1.9–4.3 × \times lossless speedup, outperforms isotropic baselines by 12–33% ( Table   2 ), and matches or exceeds EAGLE-2 wall-clock speed on two of the four models with published heads.
 Where training-free speculation is valuable.
 Trained-drafter and training-free methods are cross-category.
A trained head buys raw τ \tau where its training distribution matches; a training-free drafter buys zero-cost, day-one deployment and still wins outright at ≤ 8 {\leq}8 B (Llama-3-8B HumanEval: 3.36 × 3.36\times vs. EAGLE-2’s 2.46 × 2.46\times ).
The trade-off flips at ≥ 13 {\geq}13 B, where the slower base forward lets EAGLE-2’s higher τ \tau convert ( 3.24 × 3.24\times vs. Goose ’s 2.38 × 2.38\times on Vicuna-33B; Table   3 ).
 Limitations.
 Our main results use batch size 1, the latency-sensitive, memory-bandwidth-bound regime where speculation is strongest.
A batch-size sweep ( Section   D.7 ) shows Goose leading at small batch and batched AR overtaking as batch size grows (crossover ≈ {\approx} 4–16), the general speculation-vs-batching trade-off.
The adjacency table stays small ( < < 7 MB), and our analysis assumes greedy decoding; production-grade batched serving and sampling-based verification  ( Leviathan et al., 2023 ) remain future work.

 Appendix C Implementation and Setup
 C.1 Implementation Details
 This section provides the full engineering details summarized in Section   4.3 .
 Dense GPU bigram adjacency table.
 The adjacency table 𝒜 \mathcal{A} ( Section   4.1 ) is implemented as a two-tier structure (dense GPU unigram tensors plus a bigram hash table).
 Tier 1 (Unigram): Two dense tensors of shape | V | × K |V|{\times}K on GPU store, respectively, the token IDs and logit-derived scores of the top- K K successors for each vocabulary token; lookup is O ⁡ ( 1 ) O(1) with no CPU transfer.
 Tier 2 (Bigram): A hash table mapping ( t i − 1 , t i ) ↦ top- ​ K (t_{i-1},t_{i})\mapsto\text{top-}K successors, exploiting the fact that two-token context substantially sharpens predictions (e.g., successors of f after def are much more predictable than f alone).
 Confidence-aware branch width.
 Branch width scales with the transition score in 𝒜 \mathcal{A} : each successor’s allocated children (from the 1 / i 1/i harmonic schedule in Step 3 of Algorithm   1 ) are further modulated by its score relative to its siblings, and successors whose score falls below 0.01 are pruned entirely.
This focuses the node budget on high-confidence successors while keeping the total tree size within B B .
 Aggressive logit harvesting.
 Every forward pass’s logits, including those at rejected branches and at prefill, are harvested into the adjacency table via a batched topk ( < < 200 µs overhead).
This populates 𝒜 \mathcal{A} far faster than the verified-positions-only strategy used in prior work.

 D.3 Prompt-Level Variance
 Across all 25 model × \times dataset settings, median  τ \tau tracks the mean closely (Pearson r > 0.98 r>0.98 ) and the interquartile range (IQR) stays within 0.5 0.5 – 2.3 × 2.3\times for 23 of 25 cases.

Overall, the tight IQR confirms that Goose ’s gains are broadly distributed across prompts rather than driven by outliers.

 D.10 Principled Dynamic-Tree Allocator: Full Grid
 Proposition   2 prescribes a linear branch schedule, which Goose approximates with a hand-tuned harmonic rule ( Section   4.1 ).
To measure what that approximation costs, we replace it with the greedy dynamic-tree expansion used by trained-drafter methods  ( Li et al., 2024a ) , parameterized by measured acceptance rather than drafter confidence: expand the global top- B B candidates under Score ⁡ ( child ) = Score ⁡ ( parent ) ⋅ p ^ ​ [ source ] ​ [ rank ] \mathrm{Score}(\text{child})=\mathrm{Score}(\text{parent})\cdot\hat{p}[\text{source}][\text{rank}] , where p ^ \hat{p} is the empirical acceptance frequency of a source’s rank- k k candidate (rank = position among a node’s candidates by draft score), calibrated on a held-out prompt set disjoint from all evaluation benchmarks; multiplied along a path, the per-rank table induces the per-depth acceptance profile.
Under independence, Score ⁡ ( v ) \mathrm{Score}(v) is the probability that v v ’s entire root path is accepted, so expected accepted tokens = = summed scores; no child outscores its parent, so the top- B B set forms a tree and greedy expansion is exactly optimal for this objective.
At strict equal budget ( B = 60 B{=}60 ) its static arm beats the deployed heuristic on 17 of 19 full-size cells (geometric mean + 5.9 % +5.9\% ; Table   16 ).
The two losing cells, GSM8K on the 8B Llamas, share one cause: long verbatim repetitions push the realized spine acceptance far above its trace average, so the static p ^ \hat{p} under-builds the deep spine.
The deployed heuristic can thus be read as a hand-tuned approximation that the principled allocator subsumes.

 E.1 Proof of Proposition  1 (Spine Tree Expected Yield)
 Proof.
 We use the indicator random variable (IRV) decomposition introduced for speculative decoding by Leviathan et al. (2023) .
For each position in the speculation tree, let I = 𝟏 ​ [ the accepted path reaches and accepts this position ] I=\mathbf{1}[\text{the accepted path reaches and accepts this position}] .
Since τ = ∑ positions I \tau=\sum_{\mathrm{positions}}I (plus the bonus token), linearity of expectation gives
 𝔼 [ τ ] = ∑ Pr [ I = 1 ] + 1 \mathbb{E}[\tau]=\sum\Pr[I=1]+1 . 
 Spine positions ( d = 1 , … , m d=1,\ldots,m ). 
Spine position  d d is reached and accepted iff all d d spine tokens along the chain are accepted.
Under the i.i.d. acceptance model, Pr [ I = 1 ] = p s d \Pr[I=1]=p_{s}^{d} .
Summing: 𝔼 ⁡ [ spine ] = ∑ d = 1 m p s d \mathbb{E}[\text{spine}]=\sum_{d=1}^{m}p_{s}^{d} . 
 Branch positions at node i i ( i = 0 , … , m − 1 i=0,\ldots,m{-}1 ). 
A branch subtree at node  i i is entered iff (a) all i i preceding spine tokens are accepted (probability  p s i p_{s}^{i} ) and (b) the ( i + 1 ) (i{+}1) -th spine token is rejected (probability  1 − p s 1{-}p_{s} ).
Given entry, the branch token (depth offset j = 0 j=0 ) is accepted with probability ϕ i = 1 − ( 1 − p t ) w i \phi_{i}=1{-}(1{-}p_{t})^{w_{i}} .
For j = 1 , … , D − 1 j=1,\ldots,D{-}1 , each subsequent chain token is accepted independently with probability  p t p_{t} , so depth offset  j j is reached and accepted with probability ϕ i ⋅ p t j \phi_{i}\cdot p_{t}^{j} .
Summing over all offsets within the branch subtree: 
 𝔼 ⁡ [ branch at node  ​ i ∣ entry ] = ∑ j = 0 D − 1 ϕ i ​ p t j = ϕ i ​ ( 1 + ∑ j = 1 D − 1 p t j ) = ϕ i ​ ( 1 + ℓ ¯ ) , \mathbb{E}[\text{branch at node }i\mid\text{entry}]=\sum_{j=0}^{D-1}\phi_{i}\,p_{t}^{j}=\phi_{i}\!\left(1+\sum_{j=1}^{D-1}p_{t}^{j}\right)=\phi_{i}(1+\bar{\ell}), 
 where ℓ ¯ = ∑ j = 1 D − 1 p t j \bar{\ell}=\sum_{j=1}^{D-1}p_{t}^{j} as defined in the main text.
Here the “ 1 1 ” accounts for the branch token itself, and ℓ ¯ \bar{\ell} for the expected subsequent chain extension.
Multiplying by the entry probability and summing over all spine nodes: 
 𝔼 ⁡ [ synergy ] = ∑ i = 0 m − 1 p s i ​ ( 1 − p s ) ​ ϕ i ​ ( 1 + ℓ ¯ ) . \mathbb{E}[\text{synergy}]=\sum_{i=0}^{m-1}p_{s}^{i}(1{-}p_{s})\,\phi_{i}\,(1{+}\bar{\ell}). 
 Combining. 
Adding the spine contribution, the synergy contribution, and the + 1 +1 bonus token: 
 𝔼 ⁡ [ τ ] ≥ ∑ i = 1 m p s i + ∑ i = 0 m − 1 p s i ​ ( 1 − p s ) ​ ϕ i ​ ( 1 + ℓ ¯ ) +  1 . \mathbb{E}[\tau]\;\geq\;\sum_{i=1}^{m}p_{s}^{i}\;+\;\sum_{i=0}^{m-1}p_{s}^{i}(1{-}p_{s})\,\phi_{i}\,(1{+}\bar{\ell})\;+\;1. 
 The inequality holds because branches are modeled as independent linear chains; any deeper sub-branching within a branch (absent in this setup) would only add further contributions, confirming the lower-bound direction.
The bound is tight when each branch subtree is an independent linear chain with no further sub-branching.
∎

 E.3 Proof of Anisotropic Dominance
 Proof.
 Let the total node budget be B B and define p s > p t > 0 p_{s}>p_{t}>0 . 
 Step 1 (Replacement lemma).

 E.4 Numerical Verification of the Yield Bound
 We verify the yield lower bound of Proposition   1 against measured compression ratios across all five target models and five benchmarks (24 settings; the Vicuna-33B GSM8K cell is excluded because its diagnostics come from a separate run of that environment; cf. Table   3 ).
For each setting we extract p ^ s \hat{p}_{s} and p ^ t \hat{p}_{t} from the logged spine and branch statistics, estimate the average tree shape ( m , B ) (m,B) from the per-cycle tree-shape logs, and compute three quantities:
(i)  τ eq5 \tau_{\text{eq5}} , the lower bound from Eq.  1 with the optimal linear allocation of Proposition   2 ;
(ii)  τ iso \tau_{\text{iso}} , the yield of an isotropic tree with fan-out 3 and the same budget using only  p t p_{t} ;
(iii)  τ meas \tau_{\text{meas}} , the measured per-prompt mean of accepted tokens per cycle (a per-prompt convention that differs from the pooled τ \tau of Table   3 ).
 The bound is valid ( τ eq5 ≤ τ meas \tau_{\text{eq5}}\leq\tau_{\text{meas}} ) in all 24 model × \times dataset settings, confirming that Proposition   1 provides a correct lower bound.
The bound is conservative (median τ eq5 / τ meas ≈ 38 % \tau_{\text{eq5}}/\tau_{\text{meas}}\approx 38\% ), which is expected: the theory does not account for the consensus bypass mechanism ( Section   4.3 ) or multi-cycle warm-start effects, both of which raise the effective acceptance rate in practice.
 More importantly, τ eq5 > τ iso \tau_{\text{eq5}}>\tau_{\text{iso}} in all 24 settings (median ratio ≈ 1.52 × \approx 1.52\times ), empirically confirming the dominance result of Proposition   3 .
The gain correlates strongly with the heterogeneity ratio p ^ s / p ^ t \hat{p}_{s}/\hat{p}_{t} (Pearson r = 0.91 r=0.91 ), consistent with the monotonicity predicted by Step 4 of the proof ( Section   E.3 ).

 Scope of the analysis.
 The allocation analysis governs only how a fixed branch budget is
spread, not whether heterogeneous allocation helps: the 12–33%
equal-budget gains of Table   2 are measured end-to-end and hold
regardless of which tail model is assumed.
Both the geometric and the power-law optima prescribe the same operative
shape, monotone root-heavy widths, which is what the deployed

explains why the heuristic’s residual depth-side breadth is not wasteful.
