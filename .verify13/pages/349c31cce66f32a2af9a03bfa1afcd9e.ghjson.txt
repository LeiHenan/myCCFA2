       Motivation 
 Interleaved generation and MoT denoise need many short guest forwards that attend to an already cached text prefix. Exporting KV for every forward is impractical. 
 This PR makes each guest forward an ordinary prefill-only  /generate  request. It radix-matches the cached prefix by token IDs and batches through the existing SRT scheduler without model-specific scheduler code. The request is sessionless. A higher-level client owns logical sessions and recovery. 
 Request contract 
 
  input_ids  carries the cached prefix and guest-span placeholder IDs. 
  input_embeds  carries the guest rows inline or in caller-owned shared memory. 
  query_attention: "bidirectional"  lets every guest row attend the full prefix and every row in its guest span. 
  token_positions  supplies explicit  [rows]  or  [dims][rows]  non-negative signed 64-bit positions strictly below the active model context length. 
  sampling_params.max_new_tokens: 0  and  return_hidden_states: true  request a prefill-only forward with last-layer hidden states. 
 Optional  hidden_states_buffer  metadata describes an exact  float32 [rows, model_hidden_size]  caller-owned shared-memory segment. 
 
 When  hidden_states_buffer  is present, SRT validates the segment, attaches to it, writes the guest rows, closes its attachment, and echoes the same reference in  meta_info.hidden_states . SRT never creates or unlinks the segment. Without a buffer, hidden states use the existing inline response. 
 A late attach or write failure returns HTTP 400. It does not fall back to a large inline response or crash the scheduler. The obsolete  hidden_states_transport  field is rejected with migration guidance. 
 Inline and shared-memory inputs are validated before model execution for shape, width, dtype, finite values, float32 range, and position bounds. 
 Scheduler behavior 
 
 Requests use the ordinary waiting queue and batch only with the same attention mode and position dimensionality. 
 Internal requests without optional  query_attention  metadata retain causal attention. Explicit mixed modes still reject. 
 Prefix matching stops before the guest embeddings, so guest rows never enter radix cache. 
 If the full required prefix is no longer cached, the request releases staged resources and returns HTTP 400 with guidance to re-prefill and resubmit. 
 A bidirectional guest span is never chunk-split. Oversized spans reject at the API. A batch-boundary split waits until the whole span fits. 
 Batched hidden states are sliced by each request's actual extend width.
