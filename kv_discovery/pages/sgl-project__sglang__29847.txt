DSA CP Shared KV Cache

Motivation

DSA prefill context parallelism currently keeps the main MLA KV cache private on

each CP rank. This limits long-context capacity and leaves CP KV movement on

the critical path. This PR adds DSA CP shared KV cache for same-node CP ranks:

the DSA main KV cache is shared in L1 HBM, and DSA L2 HiCache host memory can be

shared by the CP group.

On GLM-5.2-FP8 / H20-3e, the shared path increases allocatable KV capacity by

about 3.47x in L1 HBM and reduces DSA L2 HiCache host memory usage by about

8x in the tested CP=8 configuration. Prefill/TTFT is the first release target,

and shared L2 HiCache host-hit restore reduces TTFT by 37.8% versus base

host-hit in the tested restore workload. Decode is functional and remains an

optimization follow-up.

This makes the current path a good fit for the prefill/P side of PD

disaggregation, while D-side decode optimization continues.

Summary of the current measured result:

- L1 HBM KV capacity: 3.47x higher allocatable KV tokens.

- L2 HiCache host memory: about 8x lower DSA KV/indexer host memory across

the CP group by using one owner allocation plus follower attachments.

- L1 prefill/TTFT: roughly on par with base, within about 2% in the main

release target scenario.

- L1 decode: functional, with a current +7.6% TPOT gap to optimize in the

4k input / 1k output / b10 benchmark.

- L2 HiCache host-hit restore: 37.8% lower TTFT than base host-hit in the

tested restore workload.

Modifications

- Add --enable-dsa-cp-shared-kv-cache for same-node DSA CP shared KV.

- Introduce a reusable SharedKV layout helper for rank-major slot translation

and L2 transfer-index selection; DSA CP is the first adapter.

- Share the DSA main KV cache in L1 HBM with a rank-major VMM layout, so CP

ranks can read peer KV directly instead of materializing a full private copy.

- Share DSA L2 HiCache host memory within the CP group, using the same

owner/follower synchronization shape as SharedMLA ( feat(hicache): shared L2 KV cache pool for MLA models (SharedMLA) #28027).

- Replace the former KV all-gather happens-before edge with a mandatory CP write

fence before peer KV reads.

- Keep DSA indexer HBM private in this phase, and add tests/docs for the L1/L2

shared main-KV path.

Design Notes

- L1 uses a rank-major shared KV layout. Each CP rank writes its owner pages;

attention reads through the translated global page table.

- L2 uses shared host memory for the DSA main KV. Rank 0 owns storage backup,

and restore writes each rank's owner shard back into local HBM.

- The shared-KV layout helper is generic, while this PR only enables the DSA

adapter.
