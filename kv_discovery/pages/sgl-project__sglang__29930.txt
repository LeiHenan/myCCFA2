Motivation

GLM-5.2 supports 1M-token context, so production prefill must hold very large prefix KV caches — especially in multi-turn workloads. On a PD-disaggregated prefill node with DSA prefill context parallelism, every attention-CP rank stores the same full KV cache (all layers). That duplicates identical KV across ranks and wastes most of the GPU/host memory budget; the per-rank token capacity stays small, long inputs get rejected, and multi-turn prefix reuse thrashes.

Inspired by Zhipu's LayerSplit idea, this PR splits the KV cache along the layer dimension across the attention-CP group: each CP rank stores KV only for its owned block of layers (plus one transient slot), instead of replicating all layers on every rank. At attn_cp_size = N this raises the effective token capacity of both the L1 (GPU) and L2 (host HiCache) tiers by close to N×, at the same --mem-fraction-static and --hicache-ratio. This is targeted specifically at the prefill node of PD (prefill/decode) disaggregation.

Modifications

New flag --enable-dsa-prefill-cp-layersplit (prefill node only; requires --enable-prefill-cp with attn_cp_size > 1 and --disaggregation-mode prefill). Core pieces:

- CpLayerSplitKVPool routing wrapper — presents the full [layer_offset, layer_offset + num_layers) layer view to the model, but stores KV only for the rank's contiguous owned layer block in owned_pool; non-owned layers route through a single-slot transient_pool. When a rank needs a non-owned layer, its prefix KV is gathered from the owner via a CP broadcast into the transient slot before attention runs.

- Layer-split partition math (cp_utils) — owned range / owner rank / local layer count, with a layer_offset so each PP stage splits its own local layers. SGLANG_ENABLE_DSA_PREFILL_CP_LAYERSPLIT_UNEVEN=1 allows non-divisible splits (early ranks own one extra layer).

- Pool construction & memory sizing — routed through build_kv_pool_maybe_layersplit; pool_configurator computes per-token cell size from the owned+transient layer count so the reported capacity reflects the split.

- L2 HiCache (per-rank owned-layer offload) — unwrap CpLayerSplitKVPool to owned_pool at HiCache init (cache_controller, hybrid_pool_assembler) so each rank offloads/loads back only its layers; the owner waits for its owned-layer host→device load-back before broadcasting prefix KV. Requires SGLANG_ENABLE_UNIFIED_RADIX_TREE=1.

- L3 storage (file / mooncake) — storage keys are namespaced by CP rank (_cp{attn_cp_rank}_{attn_cp_size}) so owned-layer pages from different ranks don't collide on the same content hash. The guardrail permits host-tier L2 plus file/mooncake L3 and rejects other backends.

- Prefill pipeline parallelism — layer_offset carries the PP stage start; pools are built from num_effective_layers, and token capacity is MIN-synced across ranks so uneven owned-layer counts don't diverge admission/eviction.

- Disaggregation KV transfer — under layer-split every CP rank owns distinct layers and sends its own pages unfiltered; KV-transfer buffer infos are taken from the unwrapped owned pool.

The flag-off path is a strict no-op: all layer-split logic is gated on is_cp_layersplit_active(...), the unwrap helper returns the pool unchanged for non-wrapper pools

Limitations

- Prefill PD node only (--disaggregation-mode prefill).

- MLA / DSA pool architectures only (build_kv_pool_maybe_layersplit rejects other pool classes).

- Incompatible with speculative decoding.

- With --enable-hierarchical-cache, requires SGLANG_ENABLE_UNIFIED_RADIX_TREE=1, ratio-based host sizing (--hicache-ratio), and L3 limited to file / mooncake.

Reproduction

Prefill node — env + launch:

export SGLANG_DISAGGREGATION_ALL_CP_RANKS_TRANSFER=1
export SGLANG_ENABLE_DSA_PREFILL_CP_LAYERSPLIT_UNEVEN=1 # 78 layers / 8 CP ranks

# L2 HiCache only (Section B):
export SGLANG_ENABLE_UNIFIED_RADIX_TREE=1

# ... launch prefill server with:
 --disaggregation-mode prefill \
 --enable-prefill-cp \
 --cp-strategy interleave \
 --enable-dsa-prefill-cp-layersplit

# L2 HiCache benchmark (Section B), add:
 --enable-hierarchical-cache \
 --hicache-size 0 \
 --hicache-ratio 8 \
 --mem-fraction-static 0.76

Legacy aliases still work: --enable-dsa-prefill-context-parallel → --enable-prefill-cp; --dsa-prefill-cp-mode round-robin-split → --cp-strategy interleave.

Decode node also needs export SGLANG_DISAGGREGATION_ALL_CP_RANKS_TRANSFER=1 so it receives the per-rank layer blocks.

Accuracy Tests

This is a KV placement / caching change, not a compute change: the KV values a layer sees are identical — only where they live (owned_pool vs. broadcast into a transient slot) differs across CP ranks. Model outputs are unaffected; no accuracy regression is expected. (No numerical kernel change.) MMLU-Pro scores are unchanged with LayerSplit enabled vs. disabled.
