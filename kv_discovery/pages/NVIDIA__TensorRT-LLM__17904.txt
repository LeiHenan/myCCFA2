Description

This pull request introduces support for pipelined KV cache transfer, allowing each prefill chunk to be transferred as soon as it is computed, rather than waiting for the entire prompt to finish. The changes add chunk-aware block projection utilities, update session and metadata handling for chunked transfers, and include compatibility checks to ensure pipelined transfer is only enabled in supported configurations. Several internal APIs and behaviors are updated to support chunked transfer, error propagation, and session management.

Pipelined KV Cache Transfer Support:

- Added the project_blocks_to_chunk function to efficiently project block IDs to the current chunk, enabling chunked transfer of KV cache blocks. [1] [2]

- Introduced the pipeline_transfer_enabled property and has_inflight_transfer method to indicate and manage pipelined transfer state. [1] [2]

- Implemented the _build_prefill_chunk method to construct KV slices for each prefill chunk and updated respond_and_send_async to use chunked slices when pipelined transfer is enabled.

Session and Metadata Handling:

- Updated the WriteMeta dataclass and related logic to track both sender and receiver slice IDs, ensuring correct addressing for chunked transfers. [1] [2] [3] [4] [5]

- Improved session status handling to immediately mark sessions as failed if any chunk encounters an error, preventing sessions from being stuck in an incomplete state.

Compatibility and Error Handling:

- Added strict compatibility checks to ensure pipelined transfer is only enabled when pipeline parallelism is 1, bounce buffer is disabled, and non-Mamba cache managers are used.

- Enhanced cancellation and session cleanup logic to avoid premature deletion of requests and to handle pipelined session lifetimes correctly. [1] [2] [3]

Block and Slice Management:

- Updated _create_kv_slice to support resident block bounds and ensure only computed blocks are included in chunked transfers, with correct handling of scratch, stale, and reused blocks. [1] [2] [3] [4]

- Modified block trimming and projection logic to work with chunked and partial slices, ensuring correctness for both full and partial prompt transfers.

API and Import Updates:

- Exported project_blocks_to_chunk for use in transceiver logic and updated imports accordingly.

These changes collectively enable and robustly support pipelined KV cache transfer, improving efficiency for large prompt handling while maintaining correctness and error resilience.
