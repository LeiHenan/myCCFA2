# Prior-art sweep: batch/scheduling-induced nondeterminism in LLM inference (2024–2026)

Mechanism labels: **A** = batching / batch-size / reduction-order / split-K / kernel-scheduling induced numerical divergence (TARGET);
**B** = KV-cache / prefix-caching / continuous-batching cache-reuse changing results (different mechanism);
**C** = GPU atomics / non-deterministic kernels generally, without batch dependence (adjacent).
